メーカーは、自分のキャラクター・作戦・アイテムを作るための道具です。プログラミングは要りません。この章では、「何から始めて、どうやってゲームで遊ぶか」を、手順どおりに説明します。

メーカーの種類

ゲームの画面から「メーカー」を開くと、入口のページ（メーカー入口）が出ます。いくつか種類がありますが、迷ったら「統合メーカー」だけ使えば大丈夫です。

名前作れるものこんな人に
統合メーカー（おすすめ）ユニット、武装、スキル、アイテム、作戦、研究、雇用、フラグなど、すべて全部まとめて作りたい人。新しい機能も全部ここ。
Unit Makerユニットだけ仲間・敵だけ作って配りたい人。
Mission Maker作戦だけ既存のユニットを使って、作戦だけ作りたい人。
Item Makerアイテム（と研究）だけアイテムだけ作りたい人。

この章は、統合メーカーを中心に説明します。ほかのメーカーも、画面の作りはよく似ています。

作る前に知っておきたい3つのこと

  1. 「かんたん」と「詳細」：画面の上のスイッチで切り替えます。「かんたん」は、よく使う項目だけが出ます。慣れるまでは「かんたん」で十分です。細かく調整したくなったら「詳細」に。
  2. テンプレートから作る：ユニット、作戦、アイテム、スキル、武装には、ひな形（テンプレート）があります。種類と強さを選んで名前を付けるだけで、ちゃんと動くものができあがります。最初はテンプレートから作るのがおすすめです。
  3. 自動保存：編集内容は、ブラウザに自動で保存されます（画面の右上に「自動保存済み」と出ます）。ただし、ブラウザのデータを消すと消えてしまうので、区切りのよいところで「統合JSを書き出す」でファイルにして、大切に取っておいてください。

はじめの1本：仲間と敵と作戦を作って遊ぶ

ゆっくりでも20分ほどで、自分だけの作戦で遊べます。

  1. 統合メーカーを開く。「ユニット」タブを押し、「＋ テンプレートから作る」。
  2. 味方を作る：「歩兵」など役割を選び、強さ（普通など）と使い方（「味方として使う」）を選び、名前（例：リン）を入れて「この内容で作る」を押します。同じように、もう1体作ってもOKです。
  3. 敵を作る：もう一度「テンプレートから作る」。使い方で「敵として出す」を選び、強さは「弱い」。名前は「訓練用ドローン」など。作戦の敵にできるのは「敵として使用可能」のユニットだけです（この選び方なら自動で設定されます）。
  4. 「ミッション」タブへ。「＋ テンプレートから作る」で「殲滅作戦」、RANKは「E」を選び、名前を付けます。敵は自動で選ばれます（あとで変えられます）。
  5. 作戦の編集画面の「敵編成・テスト」ステップで、敵の編成を確かめます。「難易度を計算」を押すと、パック内の強いユニットで試して、推定勝率とおすすめの報酬が出ます。「テスト戦闘する」で、1回だけ戦わせて、戦闘ログを見られます。
  6. 「パック・出力」タブを開き、パックの名前（例：マイ初作戦）を付けます。「作り方の確認」に問題が出ていなければ、「統合JSを書き出す」を押します。ファイルがダウンロードされます。
  7. ゲームで読み込む：ゲームの「データ管理」を開き、「📂 データファイルを読み込む」の「ファイルを選ぶ」から、さっきのファイルを選びます。内容が確認されるので「OK」。
  8. ゲームの「01 部隊」と「02 作戦」に、作ったユニットと作戦が増えています。遊んでみましょう！
うまく読み込めないとき

メーカー側の「パック・出力」に赤い文字で理由が出ていれば、それを直してからもう一度書き出してください。ゲーム側でエラーが出たときは、メッセージ（「○○が見つかりません」など）の指す項目を直します。ほとんどは「敵として使用可能になっていない」「参照している他のデータがパックに入っていない」です。

一覧と編集

タブを開くと一覧が出ます。名前をタップすると編集画面になります。編集画面の上にあるステップのボタン（「1. 基本情報」「2. スキル」…）か、下の「前へ」「次へ」で順番に進みます。「← 一覧へ」で戻ります。編集画面の「複製」で同じものをコピー、「削除」で消せます（使われているものは消せないことがあります）。

ステップの中身

作るものステップ
ユニット基本情報（名前・役割・タグ・能力値）→ スキル → 武装 → 拡張（隊列・AI・成長・加入条件・スキルツリー・パイロット・出撃費用・段階変化など）
作戦基本情報（名前・RANK・報酬・説明・地形・タグ）→ 敵編成・テスト（難易度の計算とテスト戦闘）→ ドロップ → 勝敗条件・ウェーブ（勝利条件、追加の敵、ルール、出撃条件、ストーリー、イベント、フラグなど）
アイテム基本情報 → 使用条件（タグ）→ 効果 → 拡張（価格・装備品・キーアイテム・ショップの販売条件など）

便利な機能

  • 元に戻す／やり直す（「パック・出力」）：直前の編集を取り消せます。このページを開いている間だけ有効で、最大40段階です。
  • 名前を付けて編集時点を保存：途中経過を、ブラウザに3つまで保存できます。あとで「保存した編集時点を復元」で戻せます。
  • IDを自動修正：IDに使えない文字があるときなどに、直してくれます。参照している箇所も一緒に直ります。
  • IDプリセット：新しく作るデータのIDの付け方を決められます（例：unit-001の形）。
  • 一括変更：ユニット・作戦・アイテムの一覧の下で、複数を選んで、タグをまとめて追加したり、ユニットの能力に倍率をかけたりできます。変更前に差分が出るので、確認してから適用します。
  • 数値入力の±ボタン：マイナスの値を入れられる項目には「±」ボタンが出て、スマホでもマイナスを入力しやすくなっています。
  • タグの入力：入力欄にタグを書いて「＋」（またはEnter）で追加。×で削除。カンマ入りの文を貼ると自動で分けます。
  • 複製ボタン：武装・スキル・効果・ウェーブなどの行に付いています。スキルのIDは自動で付け直されます。
  • パック情報：作者、パックの版番号、必要な他パックのID。
  • 関係図と到達条件を確認：作戦・素材・研究・仲間が、何をすると手に入るかのつながりを確認できます。詰まってしまう設定（例：その作戦をクリアしないと手に入らない鍵が、その作戦に必要）を見つけられます。

武装とスキルを共通部品にする

「武装」「スキル」タブで作ったものは、共通部品です。ユニットの編集画面の「スキル」「武装」ステップで、「＋ スキルを選択」「＋ 武装を選択」と選ぶと、そのユニットが使うようになります。装備品アイテムの「装備中のスキル／追加武装」にも選べます。

  • 同じ武装・スキルを使う全員が、1か所の修正で同時に変わります。例えば「ライフル」の威力を直すと、ライフルを持つ全ユニットが変わる。
  • 共通部品の編集画面の下に、「使用先」が出ます。どのユニット・装備・段階変化が使っているかが分かり、ボタンで編集画面へ移動できます。
  • 「複製してこのデータだけ変更」を押すと、その使用元だけ専用のコピーに差し替えて、ほかへの影響を防げます。
  • 使用中のものは消せません。先に使用元から外してください。
昔のデータはどうなる？

共通部品の仕組みが入る前に作ったデータ（武装やスキルを各ユニットに直接持つもの）も、そのまま使えます。統合メーカーに読み込むと、同じ内容のものが自動で共通部品にまとめられます。

作戦を作りこむ（敵・波・勝敗条件・ストーリー）

  1. 敵編成：最初に出る敵を1〜8体選び、1体ずつ「前衛」「後衛」を決めます。後衛の敵は、近接攻撃が届きにくくなります。
  2. 勝敗条件：勝ち方（殲滅／ボス撃破／防衛／護衛）を選びます。「TURN制限」を足すと「◯ターン以内に勝てないと負け」になります。
  3. 追加の敵（波）：「前の敵がいなくなったら」「◯ターン目」「敵が残り◯体以下」「ボスのHPが◯%以下」で、あとから敵を出せます。ボス撃破の作戦で、ボスを後の波にすることもできます。
  4. 出撃条件：先にクリアする作戦、必要なキーアイテム、分岐フラグ、必要レベル。曜日の指定もできます。「隠す」を選ぶと、条件を満たすまで一覧に出ません。
  5. ドロップ：確率は「50」「50%」「1/8」のどれでも入力できます。
  6. 画面にある「勝敗条件の確認」には、ゲームで実際に表示される文章が出ます。意図どおりか見てください。

会話・イベント・分岐（フラグ）を作る

ストーリーのある作戦にするための機能です。

会話

「作戦前」「勝利後」「敗北後」の会話は、1行に「話す人: セリフ」と書きます（例：隊長: 作戦を開始する）。話す人を書かない行は、地の文として表示されます。

戦闘中イベント

「勝敗条件・ウェーブ」ステップの「戦闘中イベント」で作ります。「テンプレートから追加」で、よく使う形（3ターン目に会話、ボスのHPが半分で会話＋フラグ、など）を選ぶのが簡単です。各イベントは、一覧のタイトルに「何が起きるか」が文章で出るので、設定が合っているか確認できます。

例：3つ目の波にボスが出て、そのときセリフ
  1. 「追加の敵（波）」で、第2波・第3波…と波を作り、狙いの波にボスを入れる。
  2. 「戦闘中イベント」を追加し、発生条件を「第n波登場」、値をその波の番号にする（最初の敵が第1波なので、追加の1つ目が第2波）。
  3. 「会話」に、セリフを書く。

選択肢とフラグ

  1. 作戦の「ストーリー」の「作戦前の選択肢」で、選択肢を作ります（最大8つ。選択肢は飛ばせません）。選んだときに成立するフラグを設定します。
  2. 別の作戦の「出撃条件 → 分岐条件」で、そのフラグを「成立している」にします。すると、その選択肢を選んだ人だけが、この作戦に挑めます。
  3. 戦闘の結果でもフラグを立てられます（「結果で成立するフラグ」の勝利／敗北／引き分け）。

フラグタブで、フラグに名前と説明を付けておくと、あとで見分けやすくなります。フラグの入力欄は、登録済みのものから選ぶ形です。似たつづり（boss_beaten と boss-beaten など）で新しいフラグを作ろうとすると、確認が出ます。

フラグは最初、すべて「不成立」です

フラグを立てる場所がどこにもないフラグを「出撃条件」に使うと、その作戦には永遠に出撃できなくなります。「パック・出力」の「作り方の確認」で、こうした問題を教えてくれます。

書き出す前の確認

「パック・出力」の画面で、書き出す前に次の2つを確認してください。

  • 確認と出力の問題：赤い文字で出ます。直さないと書き出せません。
  • 作り方の確認：書き出しはできるけれど、意図どおりに動かない可能性があるものです（何も起きないイベント、ボスがいない作戦のボスHPイベント、効果のない選択肢など）。「直す」ボタンで該当画面に移動できます。

アイテムを作る

  1. 「アイテム」タブで「テンプレートから作る」。回復薬、強化薬、装備品などから選びます。
  2. 「使用条件」ステップで、使えるユニットのタグを決めます（例：「生身」を持つユニットだけ）。
  3. 「効果」ステップで、効果を設定します。複数の効果を足してもかまいません。
  4. ショップで売りたい場合は、「拡張」ステップで価格を入れます。装備品にしたい場合は「装備品にする」をオン。キーアイテム（鍵など）にしたい場合は「キーアイテム」をオン。

仲間を雇えるようにする（雇用）

  1. 雇わせたいユニットを、ユニットタブで作っておきます。
  2. 「雇用」タブで「＋ テンプレートから作る」（または白紙から）。雇うユニットと雇用費を決めます。
  3. 雇える条件を決めます：クリアが必要な作戦、完了が必要な研究、必要なキーアイテム、経過日数。何も入れなければ最初から雇えます。
  4. 「雇える上限」に数を入れると、その人数までしか雇えなくなります。空欄なら無制限。

ユニット側で、加入条件を付けて「雇用でしか手に入らない」ユニットにするのもおすすめです。

書き出したデータを配る・保存する

  • 書き出された統合JSファイルは、普通のファイルです。メールやメッセージ、クラウドで渡せます。受け取った人は、ゲームの「データ管理 → データファイルを読み込む」で読み込めます。
  • ファイルの名前は、パックIDがもとになります。
  • パックには、作者・版番号・必要な他のパックを書けます。他のパックが前提のパックを作るときに使ってください（読み込むときに「必要パックが未読込」と警告が出ます）。
  • 共有するときは、他人の作品の画像・文章・音楽を勝手に使わないようにしましょう。二次創作の場合も、元の権利者の許可の範囲で、非営利で楽しんでください。

ゲーム側のパックの管理

  • パックをゲームに入れるとき、追加・変更・削除の内容と、他のパックとのID重複、使用中のユニットや装備が消えてしまう場合などの警告が出ます。
  • 入れる直前の状態は、1件だけバックアップされます。「データ管理」の「直前のパック更新前へ戻す」で、進行状況ごと戻せます。
  • 同じパックIDのパックを読み込むと、更新されます（二重にはなりません）。
