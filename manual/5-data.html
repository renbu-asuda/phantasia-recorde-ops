このゲームのデータは「ユニット」「武装」「スキル」「アイテム」「作戦」「研究」などの部品でできています。この章では、それぞれの部品にどんな項目があり、何を入れるのかを一覧にします。メーカーで作るときの辞書として使ってください。

覚えておくこと

● IDは、データ1つ1つにつける名札です。英数字・「_」（アンダーバー）・「-」（ハイフン）だけで、同じ種類の中で重ならないようにします（例：soldier_01）。メーカーが自動で付けてくれるので、普段は気にしなくて大丈夫です。

● タグは、ユニットや作戦に付ける「ラベル」です。「歩兵」「生身」「装甲車」など。アイテムの使用条件や、スキルの特効（装甲車に強い）、作戦の出撃制限に使います。1つのデータにつき最大16個、1つのタグは1〜32文字。完全に同じ文字のときだけ一致します（「歩兵」と「歩兵 」は別物）。

データの全体像

部品役割何に使われる？
ユニット仲間・敵の1体分。能力と、使う武装・スキルを持つ。部隊、作戦の敵
武装攻撃手段。威力や当たりやすさなど。ユニットが使う
スキル条件を満たすと自動で発動する特殊能力。ユニット、スキルツリー、パイロット
アイテム回復薬、強化薬、装備品、キーアイテムなど。ドロップ、ショップ、研究の支給
作戦戦い1つ分。敵の編成、勝利条件、報酬など。ゲームの「02 作戦」
研究お金を払って解放する要素。仲間の加入、ショップ追加
雇用候補お金で雇える仲間の設定。ゲームの「雇用」
地形戦場の特徴（命中・MOBへの補正）。作戦
フラグ辞書分岐フラグの名前と説明のメモ。メーカー上の管理用（ゲームの動作には影響しません）

これらを1つにまとめたものが統合パック（統合JSファイル）です。「武装」と「スキル」は、パックの中に共通部品として1つ作っておき、複数のユニットが同じものを使い回せます。共通の武装を直すと、それを使う全員が変わります（1.14以降）。

ユニット

項目意味・入れる値
名前、ID名前は表示用。IDは英数字・_・-。
役割カードに出る短い説明（歩兵、狙撃兵など）。
戦闘記号戦闘画面のアイコンに出る1〜3文字。空欄なら名前から自動。
分類タグ最大16個。
HP / ATK / DEF / MOB / ACC能力値。整数。HPは1以上、他は0以上。基準は 3000 / 250 / 0 / 500 / 500（7章）。
出撃できる側「味方として編成可能」「敵として使用可能」。両方ONもOK。作戦の敵として使うには「敵として使用可能」が必要。
武装1〜24個。
スキル0〜24個。
標準の隊列前衛（標準）／後衛。
AIの狙い方ランダム（標準）／HPが最も低い相手／ATKが最も高い相手／指定タグ優先。
成長値レベル1つごとの能力の伸び。空欄なら自動（4章）。
撃破されたときの経験値敵として倒されたとき、味方がもらう経験値。空欄なら HP÷150＋ATK÷40。
スキルツリー最大32個のノード。各ノードに、習得スキル、必要SP（0〜99）、必要レベル（1〜99）、先に覚える前提ノード。
加入条件「最初は部隊にいない」にして、作戦クリア・アイテム・研究で加入。
パイロット設定「パイロットが必要」（機体）／「乗せられる」／「自分で戦う」。「パイロットとして乗る」を設定すると、他のユニットに乗れる。搭乗時の能力補正、適性、スキル、補正の成長%（標準2%）。
出撃費用出撃1回ごとに払うお金。0〜。
装備枠の数0〜6（標準2）。
解雇できない重要ユニットにする。
段階変化最大16段階。条件（HP・ターン・生存数）を満たすと能力・武装・スキル・狙い方が変わる。
画像約300KBまで（自動で縮小）。PNG/JPEG/WebP/GIF。

武装

項目意味範囲・標準
武装名表示名。同じユニットの中で同名の武装は1つにまとめられるので、名前は変えましょう。
攻撃方式近接／射撃。近接は後衛に届きにくい。標準：射撃
属性物理／ビーム／特殊／幻想。耐性スキルとの組み合わせでのみ意味を持つ。標準：物理
基礎攻撃力ユニットのATKとは別に足す、武装固有の攻撃力。0〜1000000
ATK参照ONなら、ユニットのATKを足す。OFFなら基礎攻撃力だけ（固定火力）。OFFだとATK強化の影響を受けない。標準：ON
威力%攻撃力にかける倍率。100%でそのまま、220%で2.2倍。0〜1000000、標準100
命中補正 pt命中率にそのまま足す。−100〜100、標準15
CRIT補正 ptクリティカル率に足す（基本5%）。−100〜100、標準0
同時対象数1回の攻撃で狙う相手の数。1〜8、標準1
抽選ウェイト複数の武装を持つとき、選ばれやすさ。0.01〜、標準1
最小／最大HIT1回の行動で撃つ弾数の幅。1〜100、標準1〜4
1HIT威力%1発あたりの威力の割合。連射武装は低く、単発は100%。標準25
最低ダメージDEFが高くても、最低限通るダメージ。標準50
使用回数1戦闘で何回まで使えるか。空欄で無制限。0〜99
再使用待ちTURN使ったあと、何ターン使えないか。0〜99
DEF貫通%相手のDEFを無視する割合。0〜100
演出色弾道とダメージ表示の色（カラーピッカーで選べます）。
追加効果使用前・使用後に働く効果。最大4個。

1発のダメージ例：標準のライフル（基礎攻撃力250、威力100%、1HIT威力25%）を、ATK250のユニットが使うと、(250＋250)×100%×25% ＝125（相手のDEFが0のとき）。

スキル

項目意味
スキル名、ID
発動タイミング3章の表のとおり。タイミングによって、選べる効果が変わります。
効果、効果値何が起きるか、その大きさ。
発動率0〜100%。
使用回数1戦闘で最大何回。0は無制限。
追加の発動条件HP、ターン、生存数、相手のタグ。「すべて満たす」「どれかを満たす」で組み合わせ可（入れ子は4段まで）。
効果対象自分／味方全体／HP割合が最も低い味方／敵全体／攻撃相手／ランダムな敵1体など。
持続TURN強化・弱体・スタン・炎上・挑発の長さ。
耐性対象「属性耐性」を選んだとき、どの攻撃に強いか。
複合スキルの効果最大8個。設定すると、上の単独の効果の代わりに、まとめて実行される。

アイテム

項目意味
名前、説明、ID
使用条件（タグ）「すべて必要」「どれか必要」「持っていると使えない」の3種類。空欄なら誰でも使える。
効果1〜8個（装備品・キーアイテムは0個でも可）。下の表。
価格ショップで売る値段。空欄なら非売品。売却は半額。
使用範囲選んだ1体／部隊全員。
1体あたりの使用回数空欄は無制限。
装備品装備中だけ働く、能力補正・スキル（最大8）・追加武装（最大4）。
キーアイテム使えないが、持っていると条件を満たす（作戦の出撃条件など）。
ショップの販売条件特定の研究を終える／特定の作戦をクリアするまで並ばない。

作戦

項目意味
名前、ID、説明、RANKRANKはE〜S、SSなど。経験値の自動計算に使われます。
報酬勝ったときのお金。
出撃上限1〜8。
敵の編成最初に出る敵（1〜8体）。1体ずつ前衛／後衛を決められる。
地形標準／市街地／…／パック独自の地形。「この作戦だけ効果を変える」設定もある。
勝敗条件殲滅／ボス撃破／防衛／護衛。護衛やTURN制限は組み合わせ可。
追加の敵（波）最大9つ。登場の条件と前衛・後衛。
ルールTURN制限、決まったターンの援軍、出撃できるユニットのタグ制限。
出撃条件先にクリアが必要な作戦、持っていなければいけないキーアイテム、分岐フラグ、必要レベル。
曜日出撃できる曜日。全部オフなら毎日。
星の条件最大3つ。標準は「勝利／撃破された味方なし／10TURN以内に勝利」。ほかに「値TURN以内に勝利」「残りHP合計が値%以上」。
ドロップ勝ったときに出るアイテムと確率（%または分数）、個数。
ストーリー作戦前／勝利後／敗北後の会話、作戦前の選択肢（最大8）。
戦闘中イベント最大32。会話、地形変更、フラグ。
結果で成立するフラグ勝利・敗北・引き分け別。
表示未解放のときは隠す、を選べる。

戦闘中イベントの発生条件

条件意味
TURN到達指定したターンに達したとき。
第n波登場第n波の敵が登場したとき。最初の敵が第1波、追加の波は第2波から。
ボスHPが%以下ボスのHPが指定の割合以下になったとき。
指定ユニット撃破指定したユニットが倒されたとき。

どのイベントも、1つの戦闘で1度だけ起きます。「このユニットが出撃しているときだけ」という絞り込みも付けられます。

研究・雇用候補

部品項目
研究名前、説明、費用（資金・素材アイテム）、先に完了が必要な研究、完了したときの効果（加入するユニット／ショップに並ぶアイテム／支給アイテム）、表示（隠す）。
雇用候補雇うユニット、雇用費、上限人数、雇える条件（作戦クリア・研究・キーアイテム・経過日数）、表示（隠す）、紹介文。

地形・パック情報

  • 地形（パックごとに最大50）：名前（20文字まで）、近接の命中補正、射撃の命中補正（−100〜100）、MOB補正%、出撃できないタグ。
  • パック情報：パックID、パック名、作者、パック版番号、必要な他パックのID。
  • フラグ辞書：フラグのID、名前（40文字まで）、説明（200文字まで）。

パックの形式（Schema）と古いゲーム

データには「形式の番号（Schema）」が付きます。新しい機能を使ったときだけ番号が上がり、新機能を使わなければ、古いゲームでも読めます。新しい形式は、古いゲームでは「未対応」と表示されて読み込まれません（間違った動きをしないための安全策です）。メーカーが自動で番号を決めるので、手で気にする必要はありません。詳しくは8章。
