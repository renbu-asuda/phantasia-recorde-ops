このパックのユニット

既存の outer_ops_units.js を読み込めば、そのまま編集できる。スマホでも FileReader 方式なので fetch は使わない。
初めて作るときの目安
まず「歩兵型」などのプリセットから始めると調整しやすい。ACCとMOBが同値なら基礎命中70%。差100で10ポイント動く。基準はHP3000・ATK500・DEF0・MOB/ACC500。高機動・防御・火力型はフォックス・タートル・タイガーの能力値に準拠。連射武器はHIT数を増やす代わりに「1HIT威力%」を下げる。

パイロット（1.10.2: ユニットとして作ります）

パイロットはユニットとして作ります。自分で出撃でき、ゲームの「育成」で機体に搭乗させると補正・スキルを与えます。ユニットの「拡張」ステップで「パイロットとして他のユニット（機体）に乗れる」をONにしてください。機体側は「パイロット」を「パイロットが必要（機体）」にすると、パイロットなしでは出撃できなくなります。旧形式のパイロットは読み込むと自動でユニットに変換されます。

ツール：勝率シミュレーター・ダメージ計算機

2. 機体性能
各性能は 数値入力 と 調整ゲージ のどちらからでも設定できる。実際に保存・戦闘へ使われる値は常に数値欄が基準。数値欄に上限はなく、ゲージ範囲を超えた場合はゲージだけ端で止まる。テスト統合パック準拠の初期目安は 歩兵 HP 3,000前後 / ATK 500前後 / DEF 0 / MOB・ACC 500前後。数値欄は上限なし。

命中率の基礎値。相手MOBとの差100で命中率が10ポイント動く。
戦闘時の目安
命中率 = 70 + (ACC − 相手MOB) ÷ 10 + 武装命中補正pt。基礎1HITダメージ = max(最低DMG, ((ATK × 武装威力%) − DEF) × 1HIT威力% × 90～110%乱数)。その後に与ダメージ補正 → CRIT → 耐性・軽減を適用する。最低DMGは基礎値の下限なので、耐性後は下回ることがある。ここでは標準相手を ACC 500 / MOB 500 / DEF 0 として概算する。
3. 特殊スキル
戦闘中に実際に発動する能力をここで作る。耐性は物理・ビーム・特殊だけでなく近接・射撃にも設定できる。複数耐性が同時に該当した場合は残りダメージへ順番に軽減し、合計で最低5%のダメージは通る。

4. 武装
武装は1つ以上必要。属性は「近接/射撃」と「物理/ビーム/特殊」を別々に選び、その組み合わせで表す。AIは抽選ウェイトでランダム選択し、連射・連撃は1HITずつ命中判定する。
5. 拡張（1.9）
画像・隊列・AI・レベル成長・加入条件・スキルツリーを設定します。使わない項目は空欄のままで大丈夫です（すべて空欄ならSchema 2で書き出し、旧バージョンのゲームでも読めます）。
