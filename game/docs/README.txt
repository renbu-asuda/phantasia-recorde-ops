PRO Toolkit 1.13.0 — ユニットシステムアップデート（雇用・解雇・複数所持・出撃費用・装備枠）

雇用・解雇
- 基地メニューに「雇用」画面を追加。資金を払って仲間を雇えます。同じユニットを何体でも雇え、2体目からは「タイガー #2」のように番号がつきます。
  雇用カードには ★強さ・能力・出撃費用・装備枠・所持数（上限）・★1つあたりの費用・雇える条件を表示。部隊にいない役割（回復・前衛・後衛）は「おすすめ」と表示します。
- 雇える条件は「最初から」「作戦クリア」「研究完了」「キーアイテム」「経過日数」の組み合わせ。条件を満たすまで🔒付きで見せるか、隠すかを選べます。
  条件を満たした新しい雇用候補は「次にやること」に出ます。
- ユニット一覧の「詳しく」に「呼び名を変える」と「解雇する」。解雇は確認つきで、装備はアイテム一覧に戻り、搭乗中のパイロットは降り、編成・プリセットから外れます。雇用費は戻りません。
  重要ユニット（メーカーで「解雇できない」にしたもの）と、最後の1体は解雇できません。
- しくみ: セーブに名簿（roster）を追加し、ユニットを「個体」で管理するようにしました。1体目のIDは今までのユニットIDと同じなので、今までのセーブはそのまま続きから遊べます
  （レベル・HP・装備・搭乗・疲労などはそのまま。初回の読み込みで自動的に名簿ができます）。個体ごとにHP・レベル・装備・パイロット・疲労・スキルツリーが別々で、戦闘でも別のユニットとして動きます。
  セーブの書き出しは version 2（読み込みは1・2どちらも可）。

出撃費用・装備枠
- ユニットに「出撃費用」を設定できます。出撃するたびに、勝敗に関係なく部隊全員ぶんを資金から引きます。合計が資金より多い（資金がマイナスになる）ときは出撃できません。
  出撃確認画面に合計を表示し、戦闘ログ（SORTIE COST）と結果画面にも出ます。
- 装備枠の数をユニットごとに設定できます（0～6、標準2）。新しいアイテム効果「装備枠を増やす／減らす」（±1～3、最大8枠）で個体ごとに増減でき、減ってあふれた装備はアイテム一覧に戻ります。

研究・作戦の「未解放のときは隠す」
- 作戦と研究に「未解放のときの表示: 🔒付きで見せる／隠す」を追加。隠す作戦は前提作戦・キーアイテムの条件を満たすまで作戦一覧に出ません（曜日の条件だけのときは隠しません）。隠す研究は前提研究が終わるまで出ません。

ドロップ率の分数
- ドロップ率を「50」「50%」のほか「1/8」のような分数でも入力できます。分数は分数のまま保存され、ちょうど 1/8 の確率で抽選します。作戦カードには「1/8（12.5%）」と表示。

今日の曜日
- ゲーム上部の資金の隣に「今日: 火曜日」を表示。曜日の条件がある作戦は、カードで「今日出撃できる／今日は出撃できない」を色分けします。

メーカー
- 統合メーカーに「雇用」タブ。雇えるユニット・雇用費・上限・条件（作戦・研究・キーアイテム・経過日数）・隠す・紹介文を設定できます。存在しないユニットはエラー、条件の参照先がパックにないときはお知らせ。
- Unit Maker・統合メーカーのユニットに「出撃費用」「装備枠の数」「解雇できない」を追加。Item Maker・統合メーカーの効果に「装備枠を増やす／減らす」。
- タグ入力をすべて「入力して＋（またはEnter）」の札形式に変更（×で削除、カンマ入りの貼り付けは自動で分割）。Unit Maker の分類タグ、Mission Maker の作戦タグ、Item Maker の使用条件、統合メーカーの各タグ、出撃制限・地形の出撃不可タグなど。
- 武装・スキル・効果・ウェーブ・リストの各行に「複製」ボタン。スキルIDは自動で付け直し、武装名には「（複製）」が付きます（ゲームは同名の武装をまとめるため）。
- Unit Maker・統合メーカーから「搭乗者／操作者」の入力欄を削除（パイロット枠があるため）。今までのデータに入っている文字列は消さずに残します。

データの安全性
- 新しい項目を使ったときだけ新しいSchema番号で書き出します（使わなければ今までの番号のまま）。
  Unit Schema 6（出撃費用・装備枠・解雇不可・雇用候補）／Mission Schema 4（隠す・分数ドロップ）／Item Schema 5（装備枠の効果・隠す研究）／Bundle Schema 6（いずれか）。1.12.3 以前のゲームは「未対応」で読み込みません。
- 基本データに雇用の見本を追加: タイガー（最初から）・ミナ（最初から・上限3）・フォックス（「防衛線維持」クリアで）・ストライダー（研究「新装備の開発」で・それまで隠す）。
  ストライダー・ガーディアンに出撃費用、ジャッカルを解雇不可に、ショップに「拡張装備ラック」（装備枠+1）、研究「重装機ガーディアン配備」を前提研究まで隠すように。
- 戦闘の計算は変更なし（1.12.3 とのシード固定比較で23作戦すべて一致）。
- Game 1.13.0 / 統合メーカー 1.8.0 / Unit Maker 1.18.0 / Mission Maker 1.15.0 / Item Maker 1.8.0（PROCore 2.5.0 / PROEditor 1.7.0）。テスト32本（新規 test_roster / test_hire / test_maker_inputs）。

PRO Toolkit 1.12.3 — 攻撃属性「幻想」とブラッシュアップ

攻撃属性に「幻想」を追加
- 武装の属性が 物理・ビーム・特殊・幻想 の4種類になりました。耐性スキルの対象は、この4つと近接・射撃の6種類から選べます（幻想の武装は「幻想耐性」でダメージが減ります）。
- 属性ごとのダメージ倍率はなく、物理・ビーム・特殊と同じ扱いです（既存のパックのバランスは変わりません。1.12.2 とのシード固定比較で23作戦すべて一致）。
- 武装チップに幻想の色（ピンク）。用語の「？」に「属性」「耐性」を追加。
- 拡張パック「東方Project」のスペルカード・弾幕を幻想属性に変更。霊夢・紫・白蓮・神子は幻想耐性を持ちます。各作戦の勝率は引き続きおよそ35～95%。

データの安全性（古いゲームでの読み込み）
- 幻想を使ったパックは、新しいSchema番号（Unit 5 / Item 4 / Bundle 5）で書き出されます。1.12.2 以前のゲームは「未対応」と表示して読み込まず、誤って「特殊」扱いになることはありません。
  幻想を使わないパックは今までの番号のままで、古いゲームでも読めます。
- 注意: 東方パックは幻想を使うため、1.12.3 以降のゲームが必要です（BB・MGSPW・基本データは変更なし）。
- 1.12.3 以降のゲームも、未知の属性・耐性対象は黙って置き換えず、「未対応です」と知らせて読み込みを止めます（以前は黙って「特殊」「物理」にしていました）。

耐性スキルの作りやすさ・見やすさ
- 耐性テンプレートを物理・ビーム・特殊・幻想・近接・射撃の6種に（以前は物理とビームだけ）。武装テンプレートに「幻想弾幕」。
- 効果名「分類耐性 %」→「属性耐性 %」。耐性の対象の入力欄を「どの攻撃に強い？」にし、説明文は「幻想属性の攻撃から受けるダメージを20%減らす」のように対象を明記。武装の説明の先頭に【射撃・幻想】のように属性を表示。

戦闘ログと結果の読みやすさ
- 攻撃の行末に、耐性で減ったダメージ（「耐性で -240」）とタグ特効で増えたダメージ（「特効 +300」）を表示。
- 結果画面に「この戦闘で効いたもの」（耐性で軽減した合計と回数、特効の追加ダメージと回数）を表示。

整理
- 属性の定義を共通ファイル（PROCore.DAMAGE_TYPES / RESIST_TYPES）に一本化。ゲーム・Unit Maker・統合メーカー・エディタに散らばっていた直書きの一覧とラベル関数をやめ、不明な属性の表示を「不明」にそろえました（Unit Maker は以前「特殊」と表示していました）。
- Game 1.12.3 / 統合メーカー 1.7.0 / Unit Maker 1.17.0 / Item Maker 1.7.0（PROCore 2.4.0 / PROBattle 1.4.0 / PROEditor 1.6.0 / PROTemplates 1.3.0）。テスト29本（新規 test_damage_types）。

PRO Toolkit 1.12.0 — 作戦づくりをわかりやすく（敵の隊列・追加ウェーブ・勝敗条件・地形）

敵の前衛・後衛
- 敵編成で、1体ずつ「前衛／後衛」を切り替えられるようになりました（Mission Maker は枠の「前衛 ⇅」ボタンと一覧の「＋前衛」「＋後衛」、統合メーカーは前衛・後衛の2段表示）。
  「front, back, …」の手入力はなくなりました。隊列は「前衛 敵歩兵×2／後衛 狙撃兵」のように文章でも表示されます。

追加ウェーブ（あとから出てくる敵）
- 波ごとに「いつ出てくる？」を4種類から選べます: 前の敵がいなくなったら／決まったTURNになったら／敵が残りN体以下になったら／ボスのHPがN%以下になったら。
- 波ごとに前衛・後衛と「波の名前」（ログに出ます）を設定できます。見出しに「第2波「本隊」（敵が残り2体以下になったら）：前衛 敵歩兵／後衛 狙撃兵」のような説明が出ます。
- 盤面の敵がいなくなったときは、まだ出ていない次の波がそのTURNの終わりに出ます（条件にかかわらず）。

勝敗条件（勝ち方1つ＋追加条件）
- 勝ち方: 殲滅（敵を全部倒す）／ボス撃破（決めた敵を倒す）／防衛（決めたTURNまで耐える。敵を全滅させても勝利）。
- ボスは最初の敵だけでなく、追加ウェーブの敵からも選べます（あとの波にいるボスは、出てくるまで倒せません。倒せば残りの敵がいても勝利）。
- 追加条件: 護衛（そのユニットが倒れたら敗北）をどの勝ち方とも組み合わせられます。TURN制限（1～300）もここで設定できます。
- 「勝敗条件の確認」に、ゲームで表示される「勝利／敗北／引き分け」の文章がその場で出ます。
- 旧データの「護衛」「連戦」はそのまま読めます（護衛=殲滅＋護衛、連戦=追加ウェーブ付きの殲滅）。

引き分けは300TURN
- 決着がつかないまま300TURN経過で引き分け（これまでは30TURN）。TURN制限・防衛TURN・決まったTURNの援軍も最大300まで。
- 30TURN以内に決着する戦闘は、これまでと結果が同じです（シード固定の比較で23作戦すべて一致）。

地形の追加・編集・削除
- 作戦の地形は自由入力をやめ、リストから選ぶ形に。選ぶと「近接命中-20 / MOB-10%」のように効果が表示されます。
- 「地形を追加・編集する」で、パックに独自の地形を作れます（名前・説明・近接命中・射撃命中・MOB・出撃できないタグ）。複製・削除、組み込み10種のコピーもできます。
  組み込みと同じ名前にすると、そちらの効果に置き換わります。作戦パック・統合パックに一緒に保存され、ゲームでも効きます。

数値でマイナスが入れられない問題の修正
- マイナスを入れられる欄（地形効果・武装の命中補正やCRIT補正・パイロット補正など）は、「±」ボタン付きの入力欄になりました。スマホの数字キーボードに「-」がなくても切り替えられます。
- 全角の数字やマイナス（－・ー・−）も自動で半角に直します。マイナスにできない欄（報酬・HPなど）は今までどおりです。
- すべてのメーカーで有効です（あとから表示される武装の欄なども自動で対応）。

テスト戦闘・ゲームでの表示
- Mission Maker（難易度・テスト）と統合メーカー（敵編成・テスト）に「テスト戦闘（1回）」。ウェーブの出現・撃破・勝敗とその理由（例: 「ボス「指揮官機」を倒した」「護衛対象が倒された」）をログで確認できます。
- ゲームの作戦カードと出撃確認に、勝敗条件3行・最初の敵の前衛/後衛・追加ウェーブの説明・地形の効果を表示。

PRO Toolkit 1.10.2

パイロットをユニットに統合しました。パイロットもユニットとして作り、自分で出撃することも、機体に乗って補正を与えることもできます。
ユニットごとに「パイロットが必要（機体）」「パイロットを乗せられる（任意・従来どおり）」「自分で戦う（パイロットは乗れない・生身など）」を選べます。

- ユニットの新項目
  ・パイロット（crew）: パイロットが必要（機体）／乗せられる（任意・標準）／乗れない（生身）。
    「必要」の機体は、パイロットが乗っていないと出撃できません（部隊画面に「要パイロット」と表示）。敵として出るときは不要です。
  ・パイロットとして乗る（pilotProfile）: ONにすると、そのユニットは他のユニットに搭乗できます。搭乗時の能力補正・適性（タグ一致でATK・MOB・ACC+%）・パイロットスキルを設定します。

  ・搭乗中のパイロットは単独では出撃できません（部隊画面で「○○に搭乗中」）。「育成」でパイロットのユニットを開くと「降りる」ボタンがあります。
  ・パイロットは機体と一緒に経験値・疲労を受け、機体が撃破されるとパイロットも負傷します。パイロットが負傷中・疲労困憊なら、その機体も出撃できません。
  ・パイロットのレベルが上がると補正も伸びます（標準はLvごとに+2%。ユニットごとに0～20%で設定可）。
- 旧形式のパイロット（pilots）は自動でユニットに変換します（標準歩兵相当の生身ユニット・ハンドガン装備・タグ「生身」「パイロット」付き）。

- 初期所持品は応急修理キット1個。旧セーブでitems欄がない場合も1個から開始します。
- 作戦に勝利したときだけ、dropsの各行を独立に抽選し、結果画面に獲得数を表示します。
- 外部アイテムJSパックをGameとMission Makerで読み込めます。同じpackIdは更新、同じitem.idは後に読んだ定義が優先です。
- アイテムパックを解除しても所持数は残り、定義を再読込すると再使用できます。
- Mission MakerでアイテムID・ドロップ確率・最小/最大個数を編集・保存できます。
- Mission Pack Schema 1を維持。旧作戦にdropsがなければドロップなしとして扱います。

アイテムパックとドロップ
--------------------
同梱の outer_ops_items.js をひな形にできます。Game・Mission Makerと同じフォルダに置くと自動読込されます。
別のファイル名ならそれぞれの「アイテムJSをインポート / 追加」から選択してください。

window.VAIS_ITEM_PACK = {
  "format": "VAIS_OUTER_OPS_ITEM_PACK", "schemaVersion": 1,
  "packId": "my_items_v1", "packName": "マイアイテム",
  "items": [
    {"id":"my_kit","name":"回復キット","desc":"説明",
     "effect":{"type":"heal_hp_flat","value":1200}}
  ]
};

アイテムIDは英数字・_・-。効果は10種類に対応。使用条件は任意のrequiresで指定。新効果・複合効果の仕様は INTEGRATION.md を参照。
作戦データの各missionに任意の drops 配列を追加できます。

"drops": [{"itemId":"my_kit","chance":50,"min":1,"max":2}]

chanceは0～100（%）、minとmaxは1～999の整数でmin≦max。
この例は勝利時に50%でmy_kitを1～2個獲得します。複数行なら行ごとに抽選します。
アイテム定義がGameに未読込の場合、その行のドロップはスキップされます。

1.2.0の主な変更
---------------
- HP 0・使用不可の選択済みユニットを編成から除外し、出撃直前にも検査します。
- 各ユニットのカードから1機ずつ修理できます。全機修理も引き続き使用できます。
- 30TURNで双方が生存している場合はDRAW（引き分け）。作戦報酬の25%を回収します。
  全滅敗北時は従来どおり12%を回収します。
- 標準作戦を再調整しました。E: 出撃上限3・報酬800、D+: 出撃上限5・報酬2400。
- デフォルト装甲車のHPを8000、DEFを700に調整しました。
- 戦闘演出の待機を短縮しました。速度切り替え・一時停止・一手進むは継続します。
- Mission Makerは敵使用OFFのユニット参照を不足として警告し、編成・プレビューにも表示します。高DEF・自動回復も注意表示します。
- Unit Makerに新規ユニットの出撃側初期設定を明記しました。
- RANK・地形・タグ・特殊ルールは引き続き戦闘計算には作用しません。

戦闘基本式
----------
命中率 = 70 + (ACC - 相手MOB) / 10 + 武装命中補正pt
- 通常5～95%に制限
- ACCとMOBが同じなら70%

行動値 = MOB + 0～100
- 高MOBほど先に動きやすい

武装属性
--------
攻撃方式: melee / ranged  （近接 / 射撃）
属性:     physical / beam / special （物理 / ビーム / 特殊）

Unit Pack Schema 2 の主な武装項目
---------------------------------
powerPct      : 武装威力%。100 = ATK×1.00
accuracyPt    : 命中補正ポイント
critPt        : CRIT補正ポイント
hitPowerPct   : 1HIT威力%
minDamage     : 基礎1HITダメージの下限
attackType    : melee / ranged
damageType    : physical / beam / special

耐性スキル
----------
weapon_resist_pct と resistType で以下の5分類を指定できます。
physical / beam / special / melee / ranged

複数耐性が同時に該当した場合は残りダメージへ乗算適用します。
全軽減90% + 物理耐性90%など極端な組み合わせでも、軽減倍率は最低5%に制限されます。

旧データ互換
------------
- Gameは Unit Schema 1 / 2 の両方を読み込み可能
- Unit Maker 1.9.0も Schema 1を読み込み、Schema 2へ正規化して編集
- Mission Maker 1.8.0は Unit Schema 1 / 2を参照可能
- Mission Packは引き続きSchema 1

重要: 内部識別子は互換性維持のため変更していません。
以下は旧名称を含みますが、意図的に維持しています。
- window.VAIS_UNIT_PACK / window.VAIS_MISSION_PACK / window.VAIS_ITEM_PACK
- VAIS_OUTER_OPS_UNIT_PACK / VAIS_OUTER_OPS_MISSION_PACK / VAIS_OUTER_OPS_ITEM_PACK
- vais_outer_ops_* のlocalStorageキー
- outer_ops_units.js / outer_ops_missions.js のファイル名

これらを変更すると旧データ・既存セーブ・既存パックとの互換性が切れるためです。

Androidローカル運用
-------------------
- fetch()不要
- 同梱JSはscript srcで自動読込
- データJSの自動読込ができない場合はファイル選択で手動インポート
- shared内のプログラムJS/CSSは手動インポート対象ではありません。フォルダ構造を保って配置してください。
- 数値+ゲージ入力では数値欄が実値。ゲージは調整補助UI


1.5.0 画面の使い方
------------------
ゲーム:「部隊」で編成 →「作戦」で選択 →「出撃確認」で派遣開始。
「アイテム」で回復・恒久強化、「データ管理」で各JSパックの読み込み・解除。
メーカー: 一覧で新規作成または選択 → 編集項目を「次へ」で進む →「確認・出力」で書き出し。
上部ナビゲーションから各画面・編集項目へ直接移動できます。切り替えても入力は保持されます。
パック名・ID・読み込み操作は「パック管理」に集約。下書き復元は一覧に表示します。
各ツールへのリンクは別画面で開きます。ZIPのフォルダ構造を保って展開してください（sharedフォルダ必須）。
画面遷移はHTML内で行います。ブラウザの戻る操作ではなく画面内のナビゲーションを使用してください。
