PRO Toolkit 1.10.2

パイロットをユニットに統合しました。パイロットもユニットとして作り、自分で出撃することも、機体に乗って補正を与えることもできます。
ユニットごとに「パイロットが必要（機体）」「パイロットを乗せられる（任意・従来どおり）」「自分で戦う（パイロットは乗れない・生身など）」を選べます。
試すには、ゲームの「データ管理 → 統合JSを読み込む」で pro_1102_pilot_sample.js を読み込み、「育成」で機体にパイロットを搭乗させてから出撃してください。

- ユニットの新項目
  ・パイロット（crew）: パイロットが必要（機体）／乗せられる（任意・標準）／乗れない（生身）。
    「必要」の機体は、パイロットが乗っていないと出撃できません（部隊画面に「要パイロット」と表示）。敵として出るときは不要です。
  ・パイロットとして乗る（pilotProfile）: ONにすると、そのユニットは他のユニットに搭乗できます。搭乗時の能力補正・適性（タグ一致でATK・MOB・ACC+%）・パイロットスキルを設定します。
- 搭乗のルール（ゲームの「育成」→ パイロット）
  ・パイロット1人につき1機。自分自身・パイロットが乗れない機体・搭乗中のユニットには乗れません。
  ・搭乗中のパイロットは単独では出撃できません（部隊画面で「○○に搭乗中」）。「育成」でパイロットのユニットを開くと「降りる」ボタンがあります。
  ・パイロットは機体と一緒に経験値・疲労を受け、機体が撃破されるとパイロットも負傷します。パイロットが負傷中・疲労困憊なら、その機体も出撃できません。
  ・パイロットのレベルが上がると補正も伸びます（標準はLvごとに+2%。ユニットごとに0～20%で設定可）。
- 旧形式のパイロット（pilots）は自動でユニットに変換します（標準歩兵相当の生身ユニット・ハンドガン装備・タグ「生身」「パイロット」付き）。
  IDはそのまま引き継ぐので、旧セーブの搭乗設定も残ります（ユニットIDと重複する場合は末尾に _pilot）。ゲーム・各メーカーの読み込み時と下書きの復元時に変換されます。
- メーカー: ユニットの「拡張」ステップに「パイロット」「パイロットとして乗る」を追加。テンプレートに「人型機動兵器（要パイロット）」「パイロット（生身・機体に乗れる）」を追加。
  統合メーカーの「パイロット」タブはなくなり、パイロットもユニットタブで作ります（一覧に「要パイロット」「パイロット」を表示）。
- データ形式: 新項目を使ったユニットパックは Unit Schema 4、統合パックは Bundle Schema 3（INTEGRATION.md 参照）。1.10.1以前のゲームでは読み込めません。新項目を使わないデータは従来の番号のままで、戦闘結果も変わりません。

PRO Toolkit 1.10.1

武装に「追加効果」を付けられるようにしました。武装を使う前（使用前）と使った後（使用後）に、バフ・デバフ・状態異常などが発動します。
ゲーム本体・戦闘エンジン・データ検証・全メーカー・テンプレートが対応しています。
追加効果を試すには、ゲームの「データ管理 → 統合JSを読み込む」で pro_1101_weapon_effects_sample.js を読み込みます。

- タイミング
  ・使用前: ダメージ計算の前に発動します。ここで付けたバフ・デバフは、その攻撃のダメージにも反映されます（例: 使用前に相手のDEF-20% → その一撃から効く）。
  ・使用後: 攻撃が終わってから発動します。「いつでも／1発以上命中したとき／クリティカルが出たとき／撃破したとき」から選べます。
    「命中したとき」「クリティカルのとき」の弱体効果は、実際に命中した（クリティカルを受けた）相手だけにかかります。
- 効果（1つの武装に4つまで）
  ・両方で使える: 自分・味方・相手のATK/DEF/MOB/ACCアップ・ダウン、スタン、炎上、バリア、HP回復（割合・固定）、挑発、再行動。
  ・使用前だけ: この攻撃の与ダメージ+%、命中+pt、CRIT+pt、DEF貫通%、タグ特効%。
  ・使用後だけ（新効果）: HP吸収（与えたダメージの%を回復）、反動（自分の最大HPの%ダメージ。HPは1未満にならない）。
  ・発動率・持続TURN・効果対象（この攻撃の対象全員／自分／味方全体／最も弱った味方／敵全体／攻撃相手／ランダムな敵）・追加の発動条件（スキルと同じ7種）も指定できます。
- 反撃のときは武装の追加効果は発動しません（攻撃直前スキルと同じ扱い）。発動は1回の攻撃につき1回です。
- 戦闘ログに「[武装効果 武装名]」で表示。部隊画面のユニットカードに、各武装の追加効果を文章で表示。
- メーカー: 武装の編集欄に「追加効果」を追加。テンプレート13種（「命中したら相手のDEF-15%」「与ダメージの30%を吸収」「撃破したら再行動」など）から選べます。
  タイミングに合わない効果は選択肢に出ません。武装の説明文とダメージ計算機は、確実に発動する使用前効果を見込んで計算します。
- 武装テンプレートに追加効果付きの7種を追加（チャージ砲・アーマーブレイカー・ショックランス・ナパーム弾・ドレインブレード・指揮用信号弾・集中狙撃銃）。
  ユニットテンプレートの重装兵はアーマーブレイカー、指揮官機はナパーム弾を装備。アイテムテンプレート「武装キット：チャージ砲」を追加。
- データ形式: 武装の `effects`（INTEGRATION.md 参照）。追加効果を使ったユニットは Unit Schema 3 で出力され、1.10.0以前のゲームでは読み込めません。
  追加効果のないデータは従来どおりで、戦闘結果も1.10.0と同じです。

戦闘

PRO Toolkit 1.8.2

修正: 戦闘結果から「戦闘ログを見る」を開くと、戻る操作ができなくなる問題。
原因: 戦闘開始時に非表示にした「結果へ戻る」ボタンをログ閲覧時に再表示していなかった。
対応: 画面切替時に表示状態を更新し、戦闘終了後のログ閲覧では表示、戦闘中・結果・基地では非表示にする。

ファンタジア・レコード・オプス（PRO）1.8.1

変更点
- 同梱の全ユニット・作戦・アイテムを、提供された「テスト統合パック」に差し替え。
- 味方4体、敵歩兵1種、作戦1件、医療キット1種。名前・ID・能力・武装・スキル・ドロップ・使用条件は元データのまま。
- pro_sample_bundle.js と テスト統合パック.js は提供データと同内容。個別JSも同じデータから生成。
- 新規ユニットの能力基準: HP3000 / ATK500 / DEF0 / MOB500 / ACC500。
- 歩兵プリセットはジャッカル、高機動はフォックス、防御はタートル、火力はタイガーの能力値。プリセットは能力値だけを変更。
- 新規武装はE90。連射プリセットはE90、近接プリセットはナイフ。単発・複数特殊はE90から派生した編集用例。
- 緊急回避・緊急防御のスキルプリセットを提供パックに準拠。
- 武装の概算は相手MOB500・DEF0を基準とし、乱数・CRIT・スキルを除く表示。
- 新規作戦の初期値は難易度E・報酬1000・出撃上限8。固定HP回復の初期値は1500。
- 新規セーブの所持品は医療キット1個。ゲーム内初期化も同様。
