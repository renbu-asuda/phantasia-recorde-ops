PRO・T&D（v2.0）オンラインマニュアル

ファンタジア・レコード・オプス v2.0「PRO・T&D（タクティカル＆ディスパッチ）」の遊び方、戦いの計算のしくみ、自分だけのデータの作り方を、ゲームやプログラミングに触れたことがない人にも分かるように説明するマニュアルです。

まずここから

「とにかく遊びたい」なら1. はじめにを読んで、内蔵のチュートリアル「第零機甲教導隊」を始めてください。ゲームの中で案内役が順番に説明してくれます。分からない画面が出てきたら、そのとき2. 拠点や3. タクティカルを開けば大丈夫です。「自分で作りたい」なら7. メーカーへ。

このゲームはどんなゲーム？

あなたは部隊の指揮官です。仲間（ユニット）を部隊にまとめ、「作戦」に送り出します。v2.0 では、戦い方が2種類になりました。

戦い方どんな戦い？あなたがやること
タクティカルマス目のマップの上で、部隊を1つずつ動かして戦うシミュレーションRPG。新しく加わった戦い方です。部隊を動かす、攻撃する相手を選ぶ、施設を占領する、生産する……をターンごとに指示します。
ディスパッチこれまで（1.x）と同じ、自動で進む派遣戦。マップはありません。出撃メンバーを選んで送り出すだけ。戦闘は自動です。

どちらの戦いでも、勝つとお金・経験値・アイテムが手に入ります。それを使って拠点で仲間を強くし、次の作戦に備えます。

  1. 拠点で準備する：仲間を雇う・装備を付ける・パイロットを乗せる・研究する。
  2. 作戦を選ぶ：タクティカル作戦かディスパッチ作戦を選びます。勝つ条件や地形を確かめます。
  3. 出撃する：タクティカルなら部隊を編成してマップへ。ディスパッチならメンバーを選んで自動戦闘へ。
  4. 結果を受け取る：報酬・経験値・★評価。仲間が増えたり、拠点の機能が増えたりします。

データ（ユニット・作戦・アイテムなど）は、T&Dメーカーでプログラミングなしに自分で作れます。作ったデータは「パック」というファイルにして、ゲームに読み込むと遊べます。

このマニュアルの読み方

  • 緑の枠：知っておくと得するポイントです。
  • 黄色の枠：具体的な数字で計算してみる例です。例には、内蔵チュートリアルのユニットを使っています。
  • 赤の枠：間違えやすいところ・注意です。
  • 「もっと詳しく」の折りたたみは、気になったときだけ開いてください。読み飛ばしても遊べます。
  • 画面の名前やボタンは、ゲームの表示どおり「」で書いています。
