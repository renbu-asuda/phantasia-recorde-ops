T&Dメーカーは、ユニット・作戦・アイテムなどを自分で作り、1つの「パック」にまとめる道具です。プログラミングは要りません。作ったデータはブラウザに自動で保存されます。

T&Dメーカーとは

  • タクティカル作戦（マップ）とディスパッチ作戦の両方、それに使うユニット・武装・スキル・アイテム・研究などを1か所で作れます。
  • 作っている途中のデータ（下書き）は、このブラウザに自動保存されます。メニューの下に「自動保存しました」と出ます。
  • できたら「パック出力」でファイルにして、ゲームの「パック管理」で読み込むと遊べます。
  • 入力はすべて、項目を押して開く窓で行います。数値の範囲外などは窓の中で知らせます。
まずは内蔵パックを見てみる

チュートリアルの「第零機甲教導隊」は、このメーカーで読める形で作られています。どう作られているか知りたいときは、ゲームの内蔵パックを参考にしてください。

はじめの手順（ユニットから作戦、遊ぶまで）

  1. パック設定：パックID（半角英数字・_・-）とパック名、作者を決めます。
  2. 武装を作る：「武装」で名前・攻撃方式（近接・射撃）・威力・射程（最小・最大）・弾数や消費EN。
  3. ユニットを作る：「ユニット」で名前・サイズ・HPなどの能力・武装・MOVE・移動適性。「味方として使う」「敵として使う」を決めます。
  4. タクティカル作戦を作る：「タクティカル作戦」でマップを描き、味方の開始位置と敵の部隊を置き、勝利条件・敗北条件・報酬を決めます。
  5. 試しプレイ：作戦の「試しプレイ」で、ゲームの画面で実際に遊んで確かめます。
  6. パック出力：問題がないか確かめて、ファイルに出力します。
  7. ゲームで読み込む：ゲームの「記録・設定」→「パック管理」→「パックファイルを読み込む」→ 使う ✓ →「この内容で読み込む」。

画面の使い方と ID

  • メニュー：データの種類ごとのボタンと、「試しの状態」「パック設定」「読み込み」「PRO・Dの基本データを読み込む」「パック出力」。
  • 一覧：種類を選ぶと一覧が出ます。検索欄は名前・ID、「#タグ」でタグ検索。「＋」で新しく作ります。
  • 編集：項目を押すと入力の窓が開きます。ほかのデータを選ぶ項目（武装、作戦など）は、チェックで選びます。その場で新しく作ってつなぐこともできます。
  • 使っているデータ：編集画面の下に、そのデータを使っているほかのデータが出ます。押すとそこへ移れます。
  • 問題の表示：設定に足りないものや矛盾があると、編集画面に赤い字で出ます。

ID のルール

データには自動で ID が付きます。形は パックID-種類-6けたの番号（例：sample-U-000001）。画面では、パックIDの部分を省いて短く表示します。ID を変えると、そのデータを使っているところもすべて自動で直ります。データを消すと、そのデータへのつながりも外れます。

パックIDは早めに決める

パックIDは、ほかのパックと重ならない名前にしてください。同じパックIDのパックを読み込むと、前のものと入れ替わります。

タクティカル作戦の作り方

マップ

  • 大きさは横・縦それぞれ 6〜30 マス。基準の領域（地上・水上・宇宙）と縮尺を決めます。
  • パレットから地形を選んで、マスを押して塗ります。標準の地形のほか、自分で作った地形も使えます。
  • 味方の開始位置、敵・味方の部隊の位置、施設の持ち主（味方・敵・中立）、施設の目印、エリア（範囲）、撤退エリア、最初は隠れている範囲を置けます。

部隊

  • 敵部隊：メンバー（ユニット・パイロットとレベル・表示名）、位置、陣営（敵・第三勢力）、AI、増援（最初はいない）、格納（施設の中にいる）、捕獲できない、鹵獲したら仲間になるか、格納から出てくる範囲。
  • 味方部隊：ゲスト（あなたが動かす）か友軍（AI）。増援にもできます。
  • AI：基本の動き（突撃・待ち伏せ・拠点防衛・慎重・占領を狙う）と狙う相手、撤退・帰還するHP。さらに「AIルール」で、いつ（ターン・エリア・HPなど）何をするか（移動・守る・攻撃・補給に向かう・母艦へ戻る・変形・作戦コマンド・格納から出る・パージなど）を細かく決められます。「賢さ」をONにすると、再編成・領域の切り替え・変形・作戦コマンド・支援範囲に留まる・標的選び・撤退と回復を自分で考えます。

勝敗条件・資金・報酬

  • 勝利条件・敗北条件（種類）。「かつ」「または」で組み合わせられます。画面に出す文を自分で書くこともできます。
  • 戦場資金（陣営ごとの初期額・勝利時に持ち帰る%）、作戦の生産リスト、AIの生産、補給要請の値段、控え部隊の数、生産したユニットを持ち帰れるか、鹵獲したユニットの扱い。
  • 報酬（資金・経験値・アイテム）、ドロップ、★の条件（3つまで）と★の報酬。
  • 解放条件（先にクリアするタクティカル作戦・条件セット・解放されるまで隠す）、勝敗で変えるフラグと変数、解放・初クリアのお知らせ。

作戦の編集画面には、作り方の問題（届かない場所に敵がいる、何も起きないイベントなど）の確認も出ます。

イベントと作戦内ミッション

イベント

「いつ（発動条件）」と「起こすこと」を組み合わせます。条件を満たすと1回だけ起きます。

いつ（例）起こすこと
作戦開始／○ターン／勝利したとき／敗北したとき／部隊の撃破／ユニットの撃破／エリアに到達／施設の占領・奪われた／フラグ・変数・気力／作戦内ミッションの達成・失敗／味方が撃破された／これらの「かつ」「または」会話／選択肢／フラグ／増援を出す／部隊を撤退させる／変数を変える／部隊の気力を変える／部隊の陣営を変える（裏切り）／地形を変える／勝利・敗北条件を変える／作戦内ミッションを発生・達成・失敗にする／条件や表示文を変える／敵のAIを変える／補給／ゲームのフラグを変える／マップを広げる／撤退エリア・エリアの表示
結末を分ける

「勝利したとき」と「変数が○以上」を「かつ」でつなぐと、変数の値で勝利のあとの会話を変えられます。チュートリアルの T10 は、この方法で評判による3つの結末を作っています。

作戦内ミッション

名前、成功の条件、失敗の条件、ターン数の制限、最初から出すかイベントで出すか、報酬（資金・経験値・アイテム）を決めます。

条件セット

作戦の解放、生産・雇用、研究、ショップ、進化・合成、実績、お知らせ、拠点の解放などの「条件」は、条件セットで決めます。

  • 条件をいくつか足し、「すべて満たす」か「どれか1つ満たす」かを選びます。否定（満たさないとき）もできます。
  • 条件の例：資金を持っている／資金を消費する／アイテムを持っている／アイテムを消費する／ユニットを持っている・出撃させた／フラグ／変数／作戦をクリア済み・★の数（タクティカル作戦も選べます）／研究の完了／雇用・進化・合成した／勝利回数／日数・曜日・時刻／レベル・能力・タグ／確率。
  • 「消費する」条件は、その場面で実行したときに支払います（作戦なら出撃のとき）。拠点の解放やお知らせでは消費しません。
  • 確率の条件は、実行したときに1回だけ判定します。一覧の表示では判定しません。
  • 「試しの状態」で、資金・日数・勝利回数・フラグなどを決めて、条件が満たされるかを確かめられます。

試しプレイ・パック出力・読み込み

試しプレイ

タクティカル作戦の「試しプレイ」で、ゲームの画面を開いてその作戦を遊べます。メーカーで作ったユニットか、いまのセーブの部隊で出撃できます。試しプレイの結果は残りません（「メーカーへ戻る」で戻ります）。ディスパッチ作戦は、メーカーの中でテスト戦闘ができます。

パック出力

メニューの「パック出力」で、いまの下書きを パックID.pack.json というファイルにします。出力の前に、全部のデータの問題を一覧で見せます。そのまま出力することもできますが、問題のあるデータ（作戦など）はゲームで読み込まれません。

バックアップにも

出力したファイルは、メーカーの「読み込み」で下書きに戻せます。作業の区切りごとに出力しておくと安心です。

読み込み

  • 「読み込み」：T&D 形式のファイル（パック出力したもの）や、1.x の統合メーカーのファイル（JS・JSON）を読み込みます。1.x のデータは T&D の形に変換されます。
  • 「PRO・Dの基本データを読み込む」：公開版のユニット・作戦・アイテムを、作るときの参考として読み込みます。
下書きはブラウザに1つ

メーカーの下書きは、このブラウザに1つだけです。別のパックを作るときは、いまの下書きを出力しておいてから始めてください。
