どこで遊ぶ？ 何が必要？

インターネットにつながったブラウザ（SafariやChromeなど）があれば、スマホでもパソコンでも遊べます。アプリのインストールは要りません。ZIP版を展開すれば、オフラインでも遊べます（展開するときは、フォルダをそのまま一緒に置いてください）。

セーブデータはブラウザの中にあります

進行状況は、いま使っているブラウザの中に保存されます。別のブラウザ・別の端末・オンライン版とZIP版の間では、セーブは引き継がれません。引っ越したいときは「記録・設定」→「セーブ・ロード」→「ファイルに書き出す」でファイルを作り、新しい場所の「ファイルから読み込む」で読み込みます。

LINE の中のブラウザで開くとダウンロードや保存がうまくいかないことがあります。標準のブラウザで開いてください。

スマホでもパソコンでも

画面はスマホの縦向きに合わせて作られています。パソコンで広く見たいときは「記録・設定」→「設定」の「画面の表示」を「PC向け（広い画面）」に、文字を大きくしたいときは「文字の大きさ」を「大」にしてください。

よく出てくる言葉

難しく聞こえますが、意味はやさしいです。ここだけ押さえておけば、あとは読みながら分かります。

言葉意味
ユニット戦う仲間のこと。兵士、戦車、ロボット（機動兵器）、船など。1体ずつ能力があります。敵として出てくるものもユニットと呼びます。
部隊いっしょに動くユニットのまとまり。1部隊は8体まで、サイズの合計8までです。タクティカルでは部隊がマップの1マスにいます。
サイズユニットの大きさ。S・M・L は1、XL は2、2XL は4、3XL は8 として数えます（3XL の母艦は1体で部隊がいっぱい）。
作戦（ミッション）挑戦する戦い。タクティカル作戦（マップで戦う）とディスパッチ作戦（自動の派遣戦）があります。
HP・ATK・DEF・MOB・ACC体力・攻撃力・防御力・機動力（素早さ・かわしやすさ）・照準（当たりやすさ）。詳しくは5. 戦闘。
MOVEタクティカルのマップで1ターンに進める量。地形によって1マスに必要な量（移動コスト）が変わります。
領域ユニットがいる場所の種類。地上・空中・水上・水中・宇宙の5つ。入れるマスは領域で決まります（地上のユニットは海に入れない、など）。
移動適性領域ごとの得意・不得意。S・A・B・C・D・なし の6段階。良いほど移動コストが少なくて済みます。「なし」の領域には入れません。
施設町・補給基地・工廠・格納庫など、マップ上の特別なマス。占領すると収入・修理・生産などが使えます。
戦場資金作戦の中だけで使うお金。施設の収入で増え、生産や補給要請に使います。拠点のお金（Cr）とは別です。
局地戦タクティカルで部隊どうしがぶつかったときの小さな戦闘。最大3ターン、自動で進みます。
陣営味方（あなた）・友軍（味方のAI部隊）・敵・第三勢力（だれとも敵）の4つ。ゲストは、あなたが動かせる一時的な味方です。
気力ユニットのやる気。戦うと上下し、高いほど強くなります。0 になると「混乱」して攻撃できません。
味方支援近くの味方を強くするスキル。レーダー車や指揮官などが持っています。
作戦コマンドパイロットが使える特別な命令（必中・ひらめき・激励など）。SP や気力、戦場資金を使います。
パイロット機体に乗り込む人。乗ると機体が強くなり、パイロットのスキルや作戦コマンドも使えます。パイロットがいないと動かせない機体もあります。
SP（スキルポイント）レベルが1上がるごとに1もらえるポイント。スキルツリーで技を覚えたり、作戦コマンドに使ったりします。
パックユニット・作戦・アイテムなどのデータのセット。ゲームに読み込んで遊びます。v2.0 には「第零機甲教導隊」が内蔵されています。
T&Dメーカーパックを自分で作るための道具（ウェブページ）。プログラミングは要りません。

ほかの言葉は用語集にまとめています。

画面の見かた

ゲームは次の画面でできています。移動はすべて画面のボタンで行います。

画面何をする？
タイトル「スタート」→「はじめから」「つづきから」「設定」を選びます。中断した作戦があると、再開するかを先に聞かれます。
作戦拠点ゲームの中心。「ミッション選択へ」と、3つのメニュー「ユニット」「研究・倉庫・ショップ」「記録・設定」、右の「作戦情報」（お知らせ）があります。上には資金と所持ユニット数が出ます。
ミッション選択遊べる作戦の一覧と、選んだ作戦の詳しい情報（勝利条件・地形・報酬・★の条件・これまでの記録）。
出撃準備タクティカルなら部隊の編成、ディスパッチなら出撃メンバーの選択をします。
戦術マップタクティカルの戦場。マス目のマップで部隊を動かします。
局地戦・ディスパッチの戦闘画面自動の戦闘を見る画面。速さの変更、一時停止、一手進む、結果までスキップができます。
窓（ウィンドウ）の操作

コマンドや確認は、画面の中央に出る窓で選びます。窓は「戻る」「閉じる」のボタンで閉じてください。

最初の流れ（タイトル → パック → 最初の作戦）

v2.0 は「まっさら」の状態から始まります。遊ぶ作戦やユニットは、パックを読み込むと加わります。最初は内蔵のチュートリアルパックを読み込みましょう。

  1. タイトルで「スタート」→「はじめから」→「はじめる」。
  2. 作戦拠点の「記録・設定」→「パック管理」を開きます。
  3. 「内蔵パック（第零機甲教導隊）」を押して「✓ 使う」にし、「この内容で読み込む」→ 確認の窓で「実行する」。画面が読み込み直されます。
  4. 作戦拠点に戻ると、最初の仲間（ヴァルキス・教導歩兵分隊・ハウンド偵察車）が加わり、「作戦情報」にお知らせが届いています。
  5. 「ミッション選択へ」→「T1 初陣」を選び、「出撃」。出撃準備で部隊を組んで出撃します。あとはゲームの中で案内役が説明してくれます。
「はじめから」の注意

「はじめから」は、読み込んでいるパックをすべて外し、オートセーブを上書きします。手動のセーブスロット（3つ）は残ります。

内蔵チュートリアル「第零機甲教導隊」

新人指揮官として教導隊に配属され、演習から実戦へ進むパックです。作戦を進めるごとに、ゲームの機能を1つずつ体験できます。案内役は3人です。

  • カザマ：教導隊の隊長。作戦の目的と指揮の基本を教えてくれます。のちにパイロットとして加わり、「指揮」（味方支援）で部隊を助けます。
  • リコ：オペレーター。マップや戦闘の操作を説明してくれます。のちにパイロットとして加わり、作戦コマンドを使えます。
  • ゴウ：整備班長。拠点の機能が使えるようになると説明してくれます。

T2 部隊を組む編成（8体・サイズ8）・合流・分離・移管、武装の射程、地形生産・雇用
T3 拠点を押さえろ施設の占領・収入・修理、作戦内ミッション、★評価研究／ディスパッチ D1

拠点のメニューは、作戦をクリアするまで🔒（使えない）になっているものがあります。ボタンの下に「作戦「○○」をクリアすると使えます」と出ます。教導隊の評判は作戦の結果で上がり、最後の作戦の結末が変わります。

セーブとパック

セーブ

  • 自動で保存：拠点での操作はそのつど保存されます。作戦が終わって結果が出ると、オートセーブも作られます。
  • セーブスロット：「記録・設定」→「セーブ・ロード」で、3つのスロットに保存・読み込み・削除ができます。オートセーブは読み込みだけです。
  • ファイル：同じ画面で、ファイルへの書き出し・ファイルからの読み込みができます。端末の引っ越しや、念のための控えに使います。
  • 中断：タクティカルの作戦中に、マップのコマンド「中断して終了」で途中のまま保存できます。次にタイトルや拠点を開いたとき、再開するか破棄するかを選びます。
保存領域の使用量

「セーブ・ロード」の窓に、このゲームがブラウザに保存しているデータの量が出ます。ブラウザの上限の目安は約500万文字です。いっぱいになるとセーブできないことがあり、そのときは画面にお知らせが出ます。保存領域がいっぱいのときを見てください。

パック

  • パックは「記録・設定」→「パック管理」で、使う・使わないを切り替えます。いくつでも同時に使えます。
  • メーカーで作ったパックや配布されたパックは、「パックファイルを読み込む」でこのブラウザに取り込みます。
  • セーブは1つで、パックはそこに追加していく考え方です。パックを初めて使うと、そのパックの最初の仲間が加わります。パックを外すと、そのパックのユニットやアイテムはセーブから消えます（確認の窓で、消えるものが表示されます）。
